Agoo Traffic Corridor Interactive Simulation

This is a static website prepared from the supplied all_simulations.html.

GITHUB UPLOAD:
1. Create a new public GitHub repository.
2. Upload index.html and the three scenarios-*.js files directly to the root (not inside a nested folder).
3. Commit the uploaded files.

NETLIFY:
1. Add new project > Import an existing project > GitHub.
2. Choose the new repo, leave build command empty, and set publish directory to . (repository root).
3. Deploy, open your production .netlify.app URL, and test the scenarios.
4. Use that URL in the appendix QR code and hyperlink.

No separate build, npm or Python server is required.
The fonts are requested online from Google Fonts, with local fallbacks.
